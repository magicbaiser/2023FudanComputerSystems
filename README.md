# 计算机系统基础 (Foundations of Computer Systems)

这是复旦大学《计算机系统基础》课程的配套作业与实验内容，包含核心的系统级底层实验。通过对数据表示、汇编逆向、用户态并发以及存储层次结构的深入探索，建立起从高级语言到计算机底层硬件之间完整的系统视角。

## 🛠️ 核心工具与语言
- **开发语言**：C / C++, x86-64 汇编语言
- **开发与调试工具**：Linux (WSL), GCC, GDB, GNU Make, dlc

## 📂 实验内容规划
- **Lab 1: Datalab (数据表示实验)**
  - **核心内容**：在严格的操作符数量和控制流限制下，实现一系列高难度整数与浮点数函数。
  - **关键点**：深入理解二进制补码、位运算技巧、算术与逻辑移位、整数溢出检测以及 IEEE 754 浮点数标准的底层表示（如 `float_abs`, `float_i2f`, `mod7` 等函数的高效位运算实现）。

- **Lab 2: Bomblab (二进制炸弹与逆向工程)**
  - **核心内容**：对没有源码的编译后程序进行动态调试与逆向分析，解除多关卡的“二进制炸弹”。
  - **关键点**：熟练运用 GDB 调试器进行反汇编（`disas`）、寄存器与内存状态查看。通过分析 x86-64 汇编下的条件跳转、循环、递归调用、数组及虚函数表，推导出正确的通关密码，并解锁隐藏的终极关卡（Secret Phase）。

- **Lab 3: Coroutinelab (轻量级协程库实现)**
  - **核心内容**：理解传统函数调用栈与泛化函数（协程）之间的本质区别，手动实现一个用户态并发基础组件。
  - **关键点**：分析函数激活帧、调用栈分配及恢复流程。利用 Linux 内建的上下文管理机制（`ucontext_t`, `getcontext`, `makecontext`, `swapcontext`），封装并构建具备 `create`, `resume`, `yield`, `release` 等核心操作的用户态轻量级协程库。

- **Lab 4: Cachelab (高速缓存模拟与优化)**
  - **核心内容**：从零构建符合 LRU（最近最少使用）替换策略的 Cache 模拟器，并针对特定矩阵操作进行访存优化。
  - **关键点**：
    - **Part A**：设计并实现通用高速缓存模拟器，精确统计 Hit, Miss, Eviction。
    - **Part B & C**：针对 48 × 48、96 × 96、93 × 99 矩阵转置以及 32 × 32 矩阵乘法，运用分块（Blocking）技术、局部性原理（Locality）以及循环顺序交换，最大化减少 Cache 缺失次数。
